# OKBoard — умный переключатель раскладки для Windows 10/11

Живёт в трее и исправляет слова, набранные не в той раскладке (`ghbdtn` → `привет`, `ghbdsn` → `привіт`,
`руддщ` → `hello`). Раскладки: английская, русская, украинская. Плюс автозамена сокращений и история буфера обмена.
Главный принцип: **не мешать**. Слово меняется, только если программа уверена.

## Как он решает, что раскладка неверная

1. Слово проверяется по **словарю Windows** (тот же, что подчёркивает ошибки в системе) и по встроенному списку частых слов.
2. Исправляется, только если набранное слово **не** является словом, а вариант в другой раскладке — является.
3. Двух- и трёхбуквенные слова исправляются только по курируемому списку (`yt` → `не`, `rfr` → `как`),
   потому что словари принимают кучу сокращений («щас» не превратится в «ofc»).
4. Не трогает: слова с цифрами, `camelCase`, короткие АББР, email/URL/пути, слова, при наборе которых вы
   сами переключили раскладку, поля паролей.
5. Неизвестные слова (сленг, имена) — только по строгой буквенной статистике, иначе оставляет как есть.

## Горячие клавиши (меняются в настройках)

| Действие | По умолчанию |
|---|---|
| Исправить раскладку последнего слова (если ничего не набрано — выделения) | `Pause` или **двойной Shift** |
| Исправить раскладку всей набранной фразы | `Ctrl+Shift+Pause` |
| Исправить раскладку выделенного текста | `Shift+Pause` |
| Регистр: строчные → ПРОПИСНЫЕ → Как В Заголовке | `Alt+Pause` (можно жать несколько раз) |
| Транслитерация `привет ⇄ privet` | `Ctrl+Alt+T` |
| Режим «Не беспокоить» вкл/выкл | `Ctrl+Alt+F12` |
| Добавить последнее слово в исключения | `Ctrl+Alt+X` |
| История буфера обмена | `Ctrl+Alt+V` |
| Отменить автоисправление | `Backspace` в течение 3 секунд после исправления |

Если установлено три раскладки (EN/RU/UK), повторное нажатие `Pause` перебирает их по кругу: сначала самая
вероятная, последней — исходная.

Регистр и транслитерация работают с последним набранным словом, а если вы ничего не набирали (выделили мышью) —
с выделенным текстом.

## Возможности

- **Автоисправление раскладки** на пробеле/Enter/Tab, курсор и остальной текст не трогаются.
- **Украинская раскладка**: если установлены и русская, и украинская, слово уходит в ту, где оно настоящее
  (`ghbdtn` → `привет`, `ghbdsn` → `привіт`). Автоматически исправляется только латиница ↔ кириллица:
  русский и украинский слишком похожи, их можно переключить вручную клавишей `Pause`. Таблица клавиш берётся
  из установленной в Windows раскладки (обычная и «расширенная» украинская различаются). Если украинского
  словаря Windows нет, правила для украинского строже. Транслитерация по официальной системе (КМУ 2010).
- **Автозамена сокращений**: `мк` + пробел → полный текст. Срабатывает в любой раскладке, поддерживает
  многострочный текст и `{date}`, `{time}`, `{datetime}`; `Backspace` сразу после замены возвращает сокращение.
- **История буфера обмена** (`Ctrl+Alt+V`): окно рядом с курсором, поиск, `Enter` — вставить, `Ctrl+1…9` —
  быстрый выбор, `Del` — удалить запись.
- **Правила** (вкладка «Правила»): одно правило на строку — `[программа.exe:] шаблон = да | нет | en | ru | uk`.
  Шаблон — слово в любой раскладке, маска (`t:*`, `*.cs`, `*abc*`) или `/регулярное выражение/`. Например:
  `ofc = ru` (всегда «щас»), `t:* = нет` (поиск Unity), `Code.exe: lerp = нет`. «Нет» важнее «да», правила
  важнее исключений и словаря.
- **Ручное переключение уважается**: если вы сами только что переключили раскладку (Alt+Shift, Win+Пробел),
  следующее слово не исправляется.
- **Короткие слова по контексту**: однобуквенные и двухбуквенные слова сами по себе не исправляются, но вместе
  со следующим — да: `z ndjq` → «я твой», `f ghbdtn` → «а привет».
- **Обучение на ручных исправлениях**: исправили вручную (Pause) слово из исключений — оно убирается из
  исключений; исправили одно и то же слово вручную дважды — появляется правило всегда его исправлять.
- **Отмена Backspace + обучение**: `Backspace` в течение 3 секунд после исправления возвращает слово как было.
  Если исправление одного и того же слова отменить дважды, оно попадает в исключения и больше не трогается
  (одной отмены мало: `Backspace` часто жмут, чтобы просто стереть пробел или опечатку).
- **«Не беспокоить»**: на 15 мин / 1 час / 3 часа / пока не выключу (меню в трее или горячая клавиша).
- **Авто-пауза в полноэкранных приложениях** (игры, презентации) — там отключаются и горячие клавиши.
- **Исключения**: приложения без автоисправления (по умолчанию RDP, Hyper-V, менеджеры паролей), слова-исключения.
  Пункт в трее «Не переключать в <приложение>» — в один клик.
- **Раскладка по приложениям**: `Telegram.exe = ru`, `Code.exe = en` — включается при переключении на окно.
- **Случайный Caps Lock**: `пРИВЕТ` → `Привет`, Caps Lock выключается.
- **ДВе заглавные**: `ПРивет` → `Привет`.
- **Caps Lock как переключатель раскладки** (опционально; `Shift+Caps Lock` — обычный Caps Lock).
- **Буфер обмена не портится**: при работе с выделением он сохраняется и восстанавливается, а временный текст
  не попадает в журнал буфера `Win+V`.
- **Журнал исправлений** с кнопкой «это была ошибка — не исправлять».
- **Значок в трее** показывает раскладку крупными буквами: синий EN, красный RU, жёлтый UA; чёрный — автопереключение
  выключено или «Не беспокоить»; серый — текущее приложение в исключениях или полноэкранная пауза.
- **Автообновление с GitHub**: раз в 12 часов проверяется последний релиз; установщик скачивается, его SHA-256
  сверяется с контрольной суммой, которую публикует GitHub, и он тихо ставится, когда вы минуту не пользуетесь
  клавиатурой (после установки программа перезапускается сама). «Проверить обновления» — в меню трея; выключается
  в настройках. Портативная копия только сообщает о новой версии.
- **Светлая и тёмная тема** (или «как в Windows»): меню трея в стиле Windows 11 с иконками, окно настроек с боковой
  навигацией. Переключается в меню трея («Тема») или кнопкой внизу окна настроек.
- Корректно работает рядом со сторонними менеджерами буфера (ClipAngel, Ditto и т. п.).
- Автозапуск, один экземпляр, «сторож», который переустанавливает перехват клавиатуры, если Windows его сняла
  (второй, простейший перехват в отдельном потоке сверяет нажатия с основным; плюс переустановка после
  разблокировки и выхода из сна).
- **Словари Windows — в отдельном потоке.** Проверка орфографии Windows — межпроцессная служба, а внутри перехвата
  клавиатуры Windows запрещает межпроцессные вызовы. Поэтому все обращения к словарям идут через отдельный поток
  (перехват ждёт ответа не дольше 250 мс), а раз в 10 минут словари проверяются и при сбое пересоздаются.
- **Диагностика** в меню трея: что сейчас мешает исправлению (выключено, «не беспокоить», исключённое приложение,
  полноэкранный режим, число исключений, состояние словарей, причины решений за последний час — без самих слов),
  кнопка «переустановить перехват» и журнал
  `%LOCALAPPDATA%\OKBoard\okboard.log` (только служебные события, без набранного текста).

## Установка

Скачайте `OKBoard-Setup-x.y.z.exe` со страницы [Releases](https://github.com/alexandergolubpl/OKBoard/releases)
и запустите. Права администратора не нужны, .NET устанавливать не нужно. Есть и переносная версия
(`OKBoard-x.y.z-portable.exe`) — просто запустите её.

Начиная с версии 0.2.3 установленная программа обновляется сама (см. «Автообновление» выше). С более ранних
версий на 0.2.3 нужно обновиться вручную.

Файлы не подписаны цифровой подписью, поэтому Windows SmartScreen может показать предупреждение:
«Подробнее» → «Выполнить в любом случае».

## Сборка и запуск

Нужен .NET 10 SDK.

```powershell
dotnet build
dotnet run --project src/OKBoard

# один exe (нужен установленный .NET 10 Desktop Runtime):
dotnet publish src/OKBoard -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o publish
# полностью автономный exe (~150 МБ, ничего ставить не нужно):
dotnet publish src/OKBoard -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o publish
```

Установщик и переносная версия (нужен [Inno Setup 6](https://jrsoftware.org/isinfo.php)):

```powershell
.\installer\build.ps1 -Version 0.2.6   # результат в .\dist
```

Тесты:

```powershell
dotnet run --project tests/OKBoard.Tests            # детектор, конвертация, транслит, регистр
dotnet run --project tests/OKBoard.Tests -- --e2e   # реальное окно + реальный хук, ~4 минуты; не переключайте окна
                                                    # (если фокус уйдёт в другое окно, тест остановится сам)
dotnet run --project tests/OKBoard.Tests -- --update-live   # скачать последний релиз и проверить SHA-256 (без установки)
dotnet run --project tests/OKBoard.Tests -- --replay 30     # «напечатать» ваши запросы к Claude Code за 30 дней
```

`--replay` прогоняет через настоящий движок (виртуальная клавиатура, документ и часы, ~2 секунды на месяц) всё,
что вы печатали в Claude Code в других проектах (`~/.claude/projects`), в двух сценариях: «аккуратный» (раскладку
переключаете сами — любое изменение текста считается ошибкой) и «забывчивый» (не переключаете — считаются пропуски
и неверные исправления). Ваши тексты читаются только локально и никуда не сохраняются; на экран выводятся
статистика и проблемные слова.

Настройки: `%APPDATA%\OKBoard\settings.json`.

## Безопасность и приватность

- Набранный текст хранится **только в памяти**: буфер текущей строки — не больше 400 нажатий, он очищается при
  щелчке мышью, смене окна и навигационных клавишах. На диск пишутся только `settings.json` (настройки
  и слова-исключения) и служебный журнал `okboard.log` (запуск, переустановка перехвата, ошибки — без
  набранного текста, до 512 КБ). Журнал исправлений живёт в памяти, до 200 записей.
- **Сеть**: программа обращается только к GitHub (`api.github.com` и загрузка файла релиза) для проверки
  обновлений; никакой телеметрии. Установщик ставится, только если его SHA-256 совпал с контрольной суммой,
  которую GitHub публикует для файла, и скачан он из этого репозитория по HTTPS. Автообновление выключается
  в настройках.
- **История буфера обмена** хранится только в памяти и исчезает при выходе; её можно очистить из меню трея или
  выключить в настройках. Не записывается текст, который менеджеры паролей помечают как приватный (те же правила,
  что у истории Windows `Win+V`), текст из приложений-исключений и служебные копирования самой программы.
- **Пароли**: в Win32-полях пароля программа отключается; одиночное слово перед Enter/Tab (так вводят пароли
  в браузерах) не исправляется.
- **Буфер обмена**: вставляемый текст отдаётся с отложенной отрисовкой, а ваш буфер восстанавливается только
  после того, как приложение реально забрало текст, и только если вы за это время ничего не скопировали сами.
  Временный текст не попадает в историю `Win+V` и облачный буфер.
- **Терминалы**: операции с выделением там отключены, потому что `Ctrl+C` = прерывание программы, а вставка
  текста с переводом строки = выполнение команды. Копирование делается через `Ctrl+Insert`, `Ctrl+C` — только
  запасной вариант.
- Если вы переключились в другое окно между нажатием горячей клавиши и её выполнением, действие отменяется.
- Горячие клавиши, которые печатают символы без Ctrl/Alt/Win (например, просто `Q`), не принимаются.
- Внутри перехватчика клавиатуры нет записи на диск, тяжёлые вызовы прогреваются при старте. «Сторож»
  переустанавливает перехват, если Windows его сняла.
- Системные DLL загружаются только из System32. Права администратора программе не нужны.

## Ограничения

- В окнах, запущенных **от администратора**, программа не видит ввод (ограничение Windows UIPI),
  пока сама не запущена от администратора.
- Поля паролей распознаются только в классических Win32-окнах; в браузерах помогает то, что пароли
  почти никогда не являются словарными словами.
- Поддерживаются английская, русская и украинская раскладки.
- Сторонние менеджеры буфера, игнорирующие стандартную пометку «не записывать» (например, ClipAngel), увидят
  временный текст, который OKBoard кладёт в буфер при работе с выделением и автозаменой.

## Структура

```
src/OKBoard/
  Engine.cs            хуки клавиатуры/мыши, буфер строки, автоисправление, горячие клавиши, работа с выделением
  LanguageDetector.cs  решение «неверная раскладка?» (словарь Windows + частые слова + биграммы)
  LayoutMap.cs         клавиша ↔ символ для EN/RU, конвертация текста
  SpellChecker.cs      обёртка над Windows Spell Checking API
  TextTools.cs         транслитерация (RU и UK), регистр, Caps Lock/ДВе заглавные
  ClipboardHistory.cs  история буфера обмена (только в памяти)
  ClipboardPopup.cs    окно истории буфера
  DelayedClipboard.cs  вставка через буфер с отложенной отдачей и восстановлением
  InputSender.cs       SendInput + управление раскладкой окна
  TrayApp.cs           трей, меню, иконка, автозапуск
  Updater.cs           автообновление из релизов GitHub с проверкой SHA-256
  Rules.cs             пользовательские правила переключения
  Theme.cs             светлая/тёмная тема, отрисовка меню и элементов в стиле Windows 11
  KeyboardWitness.cs   сторож перехвата клавиатуры, журнал диагностики
  SettingsForm.cs      окно настроек
tests/OKBoard.Tests/   юнит-тесты и E2E
```
